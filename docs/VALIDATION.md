# 실행 검증

검증일: 2026-10-19. 실제 작업 환경의 Node.js 24, Python 3.12, 설치된 Chromium에서 실행했습니다. 기본 게임 실행에는 Python 정적 서버와 브라우저만 필요합니다.

## 실행한 검사

- `npm test`: 45개 테스트 통과. 건설·자재 차감·원자재 제한·도로 단절·고용·정확한 월 수지·인구·서비스 범위·구역 개발·외형 단계 성장·연구·철도 운송·선거·외국 시장 대응 장부·결정론·1950년 종료·투영/열차 경로·저장 검증을 포함합니다.
- `npm run check`: JavaScript 구문과 실제 진입 파일 검사 통과.
- `npm run build`: 자체 이미지와 소스가 포함된 정적 `dist/` 빌드 통과.
- `python3 tests/browser_smoke.py --url http://127.0.0.1:3000`: 실제 Chromium의 UI 시나리오 13개 통과. 새 게임·건물 지붕 클릭·이름 변경·보존·확장·실제 지도 건설·차감·실행 취소·도로 드래그·실제 선로 열차 애니메이션·확대·이동·서비스 레이어·야경·패널·정책·연구·시간·도시 전환·철도 연결·저장 복원·PNG 등록·390px 모바일을 확인했습니다. 페이지 JavaScript 예외 0개입니다.
- `python3 tests/browser_storage.py --url http://127.0.0.1:3000`: 실제 Chromium에서 저장 관련 8개 시나리오 통과. IndexedDB 슬롯 3개와 자동 저장, 브라우저 새로고침 후 복원, 사용자 이미지의 실제 배치와 저장 복원, JSON 파일 다운로드와 전체 상태 비교, 손상 체크섬·픽셀 손상 이미지 거부, 슬롯 삭제를 확인했습니다. 자동 저장은 실제 타이머 콜백을 240회 호출하여 60초 누적 조건과 실제 IndexedDB 쓰기를 검증했습니다.
- 실제 UI에서 1950년 12월에 8배속을 켜도 날짜가 넘어가지 않고 일시정지되는 종료 동작을 확인했습니다.
- 120개월 연속 진행 후 전체 상태 검증 통과. 기본 도시의 자원·재정·인구가 유한한 값으로 유지되고 날짜가 1910년으로 진행되었습니다.
- 모든 건물의 PNG 경로·규격·투명도와 원본 AI 방직공장 이미지 연동을 확인했습니다. 이미지 1개를 의도적으로 차단한 브라우저 검사에서도 경고와 Canvas 대체 그래픽이 작동했습니다.

브라우저 검사는 선택 개발 도구인 Python Playwright와 Chromium을 사용합니다. `python3 -m pip install playwright`로 검사 도구를 설치하고 `BROWSER_EXECUTABLE_PATH` 또는 검사 파일의 실행 경로 설정을 확인하세요. 서버를 실행한 상태에서 위 명령을 사용합니다. 테스트 도구는 게임의 런타임 의존성이 아닙니다.

이 기록은 현재 소스와 작업 환경에서 실행한 검사입니다. Replit/Vercel 계정 연결, 원격 서비스 배포, Supabase 연동, GitHub push, 다른 운영체제·저사양 기기의 성능을 검증했다는 뜻이 아닙니다.

## 부하와 시대별 화면

`python3 tests/browser_performance.py --url http://127.0.0.1:3000`에서 실제 건설 액션으로 건물 600개·도로 763개를 추가한 독립 테스트 도시를 만들었습니다. 테스트 재정과 자재를 명시적으로 충분히 설정했으며, 기본 게임의 시작 자금과 자원에는 영향을 주지 않습니다. 주택 574개가 모두 도로에 연결되었고 24개월 진행 후 재정·자원·인구·생산이 유효했습니다. 8배속 상태에서 확대·이동 중에도 여러 달의 진행을 확인했습니다. 1850년과 1936년을 실제 새 게임 화면에서 선택하고, 날짜·초기 연구·화면 속 건물 단계(1단계와 4단계)가 다르며 AI 방직공장이 지도에 표시되는 것도 확인했습니다.

측정값과 테스트 데이터는 `docs/validation/`의 JSON 보고서에 있습니다. 이 클라우드의 headless Chromium 한 번 실행 결과이며 다른 기기의 프레임을 보장하지 않습니다. 넓게 축소해 모든 타일이 보이는 상태는 일반 확대 상태보다 느릴 수 있습니다.

마지막 600개 건물 부하 검사에서 전체 보기 약 17.3fps, 확대·이동·8배속 상태 약 29.7fps를 측정했습니다. 지형·도로·선로 텍스처 캐시는 8MiB 이하로 제한됩니다. 이 수치는 해당 클라우드 브라우저 실행에만 해당합니다.

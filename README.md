# CENTURY: Nations & Cities

[게임 ZIP 다운로드](https://github.com/limwoobin9-hub/century_nation_city/raw/refs/heads/main/releases/CENTURY_Nations_and_Cities.zip) · [Vercel 프로젝트 가져오기](https://vercel.com/new)

**당신의 선택이 도시의 풍경이 됩니다.** 1850–1950년을 배경으로, 국가 재정과 여러 픽셀 도시를 함께 운영하는 브라우저 게임입니다. HTML5, CSS, ES modules와 Canvas 2D로 제작했으며 실행 중 외부 API나 인터넷 연결을 요구하지 않습니다.

## 실행

ZIP을 풀고 프로젝트 폴더에서 실행합니다.

```sh
python3 scripts/serve.py
```

터미널에 표시되는 주소를 브라우저로 여세요. 기본 포트는 3000입니다. `PORT=4000 python3 scripts/serve.py`로 포트를 바꿀 수 있습니다. Windows에서는 설치 상태에 따라 `python scripts/serve.py` 또는 `py scripts/serve.py`를 사용하세요. `npm run dev`도 같은 서버를 실행합니다.

브라우저가 `file://`에서 JavaScript 모듈과 이미지 접근을 제한하므로 `index.html`을 더블클릭하는 대신 위의 정적 파일 서버를 사용합니다. Python 3.10 이상이면 실행할 수 있으며, 패키지 설치·데이터베이스·API 키는 필요하지 않습니다. 모든 게임 이미지, 소스와 스타일이 이 프로젝트 안에 있습니다. 웹 폰트/CDN도 사용하지 않습니다.

## 첫 플레이

1. 국가와 시작 연도를 선택하세요. 기본 시나리오는 1900년이며, 이미 형성된 수도와 두 지방 도시에서 시작합니다.
2. 아래 **주거** 메뉴에서 주택을 골라 도로 옆 빈 땅에 클릭하세요. 국고와 건설 자재가 차감되고 실제 PNG 건물이 나타납니다.
3. **도로·철도·구역**은 드래그하여 연속 배치합니다. 막힌 곳은 빨간 미리보기와 이유가 표시됩니다.
4. **산업** 메뉴에서 원료 재고를 확인하세요. 농장 → 식량, 탄광·철광산 → 제철소, 목재·석탄 → 공업 생산이 연결됩니다. 원료나 도로가 없으면 생산이 제한됩니다.
5. 시간을 진행하세요. 1배속은 약 2.5초에 한 달입니다. 인구·고용·세입·서비스·재고가 월 단위로 계산됩니다. 주거 수요가 있는 도로 옆 구역에는 민간 건물이 생깁니다.
6. **국가** 화면에서 도시를 전환하거나 도시간 철도를 연결할 수 있습니다. 연결된 도시의 실제 잉여·부족 자원이 운송됩니다.
7. **연구**에서 전력·석유·자동차·도시계획 등 시대에 맞는 기술을 개발하세요. 시설이 해금되고 생산성·수용력·거리 풍경이 변합니다.
8. 우측 상단 저장 버튼으로 3개 슬롯에 저장하세요. 진행 중 60초마다 자동 저장됩니다. 중요한 도시는 JSON으로도 내보내세요.

## 조작

| 조작 | 기능 |
|---|---|
| 좌클릭 | 건설 / 건물 선택 |
| 우클릭 또는 Esc | 건설 취소 / 선택 해제 |
| 도로·철도·구역 드래그 | 연결된 구획 연속 시공 |
| 마우스 휠, + / − 버튼 | 확대·축소 |
| 가운데 버튼 드래그 또는 Space + 드래그 | 지도 이동 |
| 짧게 Space | 시간 일시정지·재개 |
| Delete | 선택 시설 철거 |
| Ctrl/Cmd+Z | 최근 건설·철거·확장 취소 |
| Ctrl/Cmd+S | 수동 슬롯 1에 빠른 저장 |
| G | 격자 표시 |
| P | 사진 모드 |

건물을 클릭하면 실제 고용·생산·연결·운영 상태를 확인하고 이름 변경, 예산 조정, 확장, 운영 중단, 보존·철거를 할 수 있습니다. 학교·병원·경찰·소방·공원·발전소의 영향은 거리와 수용력, 예산을 반영합니다. 모바일에서는 하단 도구와 화면 확대 버튼을 사용할 수 있습니다. 조작과 건설은 데스크톱 마우스 환경을 권장합니다.

## 구현 기능

- 10개 국가 계열과 이름·수도·정치체제·국기 색상·인구·산업 수준을 설정하는 가상 국가
- 1850 / 1870 / 1900 / 1920 / 1936년 시작. 연도에 따른 초기 연구·건물 단계·역사 이름·수도
- 각 100×100 타일인 세 도시, 2:1 아이소메트릭 투영, 확대·이동·깊이 정렬·건물 픽셀 선택
- 35종 건물, 4단계·4변형. 자체 제작 건물 PNG 560개, 나무 PNG 4개, AI 방직공장 PNG 1개
- 실제 건설·철거·연결 도로·철도·구역, 재정·자재 차감, 건설 취소
- 원료 생산·소비·공장 가동·고용, 식량·소비재 수요, 세입·운영비·산업 지원·국채 이자
- 주거·일자리·건강·교육·오염·세금에 따른 인구와 만족도, 6개 사회계층 집계
- 주거·상업 구역 개발, 조건에 따른 자동 건물 성장과 다른 스프라이트, 수동 확장·역사 건물 보존
- 실제 연결 선로를 따라 움직이고 양 끝 역에서 정차하는 열차, 도로 위 시민·차량, 가동 공장 연기·물결·야간 조명
- 국가 지도·도시 비교·도시간 철도 자원 운송, 관세와 양자 무역 협정
- 기술 연구·해금·예산 정책, 네 가지 정치체제·정치 개혁·정부 지지도·간단한 선거
- 타일에 직접 표시하는 인구·토지가치·실업·산업·오염·교통·교육·의료·전력·만족도 지수 레이어
- 실제 월별 기록에 연결된 인구·재정·생산·실업·행복도 등의 그래프와 연대기
- 3개 수동 저장 + 자동 저장, IndexedDB/localStorage, JSON 내보내기·가져오기와 데이터 검증
- 사용자 투명 PNG 등록 → 건설 메뉴 → 실제 지도 배치 → 이미지와 함께 저장·복원
- 사진 모드와 PNG 도시 사진 저장

## 그래픽 제작 방식

기본 건물 대부분은 프로젝트의 Canvas 픽셀 아트 코드로 직접 만들고 투명 PNG로 내보냈습니다. 지붕·벽돌·창문·문·굴뚝·승강장·광산 설비·공원 등을 표현합니다. **방직공장 변형 0은 이번 개발에서 실제 이미지 생성 도구로 만든 AI 이미지**이며, 초기 도시 지도에서도 사용합니다. 게임 내에서 건설할 때마다 이미지를 생성하거나 API를 호출하지 않습니다.

자산 출처와 규격은 [assets/ASSETS.md](assets/ASSETS.md), 이미지 목록은 [assets/manifest.json](assets/manifest.json)을 참고하세요. 이미지 로딩에 실패하면 경고를 기록하고 같은 스타일의 Canvas 대체 스프라이트를 사용합니다. PNG 재생성은 선택 사항이며 Python Playwright와 Chromium이 필요합니다.

## 저장과 개인정보

게임은 브라우저 로컬 저장소만 사용하고 사용자 파일을 외부로 전송하지 않습니다. 저장에는 국가, 각 도시의 지도·건물·자원, 재정, 인구, 연구, 정책, 날짜, 연대기, 사용자 이미지가 포함됩니다. 저장 파일은 버전·체크섬·좌표·건물 참조·이미지 크기 등을 확인한 뒤 적용합니다. 잘못된 파일은 현재 게임을 덮어쓰지 않습니다.

브라우저 데이터 삭제, 시크릿 모드 종료, 사이트 주소나 포트 변경은 로컬 저장 접근에 영향을 줍니다. 장기 보관에는 JSON 내보내기를 사용하세요. 세부 형식은 [docs/SAVE_FORMAT.md](docs/SAVE_FORMAT.md)에 있습니다.

## 개발과 배포

Node.js 18 이상에서:

```sh
npm test
npm run check
npm run build
```

실제 실행 검증과 재현 명령은 [docs/VALIDATION.md](docs/VALIDATION.md)에 있습니다.

런타임 npm 의존성이 없으므로 `npm install` 없이 실행할 수 있습니다. `dist/`에는 정적 배포 파일이 생성됩니다.

- **Vercel**: 포함한 `vercel.json`은 `npm run build`를 실행하고 `dist`를 정적 배포합니다. 저장소 연결 또는 `dist` 업로드는 이용자 계정에서 별도로 수행해야 합니다.
- **Replit**: 프로젝트를 가져온 뒤 Run을 누릅니다. `.replit`과 `PORT` 대응 정적 서버가 포함되어 있습니다.
- **GitHub**: 이 폴더는 기존 `century_nation_city` 체크아웃입니다. 게임 소스와 `releases/CENTURY_Nations_and_Cities.zip`을 `main`에 업로드했습니다.
- **Supabase**: 기본 게임은 데이터베이스가 필요하지 않습니다. 로그인·클라우드 저장·사용자별 동기화는 구현하지 않았으며 Supabase에 접속하지 않습니다.

배포 설정 파일 제공과 실제 계정 연결·서비스 배포는 서로 다릅니다. 이 결과물은 외부 계정이나 비밀 키 없이 로컬에서 플레이할 수 있습니다. Vercel 배포에는 본인의 Vercel 계정 연결이 필요합니다.
